## Launch Strategy (5阶段框架)

### Phase 1: Internal (Pre-Launch)
- 先在内部使用产品
- 在真实用例中发现bug
- 构建初始案例研究
- 创建发布内容
- 设置分析和追踪

### Phase 2: Alpha (Private Beta)
- 邀请现有客户和潜在客户
- 获取反馈和推荐语
- 根据反馈优化定位
- 构建等待列表

### Phase 3: Beta (Public Preview)
- 通过邀请码扩大访问
- 收集更多推荐语
- 优化定价和包装
- 构建SEO内容

- 公开等待列表开放
- 特殊发布定价
- 联盟/合作伙伴拓展
- 媒体和分析师拓展

### Phase 5: Full Launch
- 全面可用
- 全面推广
- 客户成功案例
- 持续优化

# PART 2: 心理学与心智模型

## Foundational Thinking Models

### First Principles
将问题分解为基本事实。不要复制竞争对手——反复问"为什么"以找到根本原因。

**Marketing application**: 不要因为竞争对手做内容营销就去做。问为什么，它解决什么问题，是否有更好的解决方案。

### Jobs to Be Done (JTBD)
人们"雇佣"产品来完成一项工作。关注结果，而不是功能。

**Marketing application**: 购买钻头的买家想要的是一个洞，而不是钻头。围绕完成的工作来构建框架。

### Circle of Competence
知道你的优势所在并保持在其中。加倍投入真正的专业知识。

**Marketing application**: 不要追逐每个渠道。专注于你真正有竞争优势的地方。

### Inversion
问什么会导致失败，然后避免这些事情。

**Marketing application**: 列出所有会导致营销活动失败的因素，然后系统地预防每一个。

### Occam's Razor
简单的解释通常是正确的。避免过度复杂化策略。

**Marketing application**: 如果转化率下降，先检查显而易见的问题（表单损坏、页面慢），再考虑复杂的归因。

### Pareto Principle (80/20)
80%的结果来自20%的努力。找到并专注于关键的少数。

**Marketing application**: 找到驱动大部分结果的渠道。削减或减少其余的。

### Hick's Law
决策时间随选项增加而增加。更多选择 = 更多放弃。

**Marketing application**: 一个清晰的CTA胜过三个。更少的表单字段 = 更高的转化。

### AIDA Funnel
Attention → Interest → Desire → Action

**Marketing application**: 构建页面以依次通过每个阶段。在建立欲望之前先吸引注意力。

### Law of Diminishing Returns
超过某一点后，额外的投资产生 progressively smaller 的收益。

**Marketing application**: 第10篇博客文章的影响不会和第1篇一样。多样化渠道。

### Commitment & Consistency
一旦人们承诺了某件事，他们希望保持一致。

**Marketing application**: 先从小承诺开始（邮件注册），然后引导到更大的承诺（付费订阅）。

### Reciprocity Principle
先给予。人们觉得有义务回报。

**Marketing application**: 免费内容、工具、免费增值模型创造互惠义务。

### Scarcity & Urgency
有限的可用性增加感知价值。

**Marketing application**: 限时优惠、库存不足警告。仅在真实时使用。

### Loss Aversion
损失的感觉是同等收益的两倍痛苦。

**Marketing application**: "不要错过"胜过"你可以获得"。用他们将失去什么来构建框架。

### Anchoring Effect
第一个数字严重影响后续判断。

**Marketing application**: 先显示更高的价格（原价、竞争对手、企业版）以锚定预期。

### Paradox of Choice
太多选项会压垮人。更少的选择导致更多的决策。

**Marketing application**: 三个定价层级。推荐一个"最适合大多数人"的选项。

### Endowment Effect
人们一旦拥有某物就会更重视它。

**Marketing application**: 免费试用、样品、免费增值模型让客户"拥有"产品。

### IKEA Effect
人们更重视他们投入努力创造的东西。

**Marketing application**: 让客户自定义、配置、构建。他们的投资增加承诺。

### Mere Exposure Effect
熟悉产生喜爱。持续的存在建立偏好。

**Marketing application**: 跨渠道的重复创造舒适和信任。

### Social Proof / Bandwagon Effect
人们跟随别人在做的。流行信号质量。

**Marketing application**: 显示客户数量、推荐语、" trending" 指标。

### Prospect Theory / Loss Aversion
人们避免可能导致后悔的行为。

**Marketing application**: 退款保证、免费试用减少后悔恐惧。直接解决顾虑。

### Zeigarnik Effect
未完成的任务占据思维。开放的循环创造张力。

**Marketing application**: "你已经完成了80%"创造完成的拉力。不完整的资料、废弃的购物车。

### Status-Quo Bias
人们偏好当前状态。改变感觉有风险。

**Marketing application**: 减少摩擦。让过渡感觉安全。"一键导入"。

### Default Effect
人们接受预选选项。默认值很强大。

**Marketing application**: 预选你希望客户选择的计划。选择退出胜过选择加入。

### Peak-End Rule
人们通过峰值（最好/最坏）和结束来判断体验，而不是平均值。

**Marketing application**: 设计难忘的峰值和强大的结尾。感谢页面很重要。

# PART 3: SEO & 内容

## SEO Audit Framework

### Priority Order
1. **Crawlability & Indexation** - Google 能找到并索引页面吗？
2. **Technical Foundations** - 网站快速且功能正常吗？
3. **On-Page Optimization** - 内容优化了吗？
4. **Content Quality** - 它值得排名吗？
5. **Authority & Links** - 它有可信度吗？

### Technical SEO Checklist

**Crawlability**
- Robots.txt 没有阻止重要页面
- XML sitemap 可访问且已更新
- 网站架构在首页3次点击内
- 没有孤立页面

**Indexation**
- 重要页面没有意外的 noindex
- 正确的 canonical tags（自引用）
- 没有重定向链
- 没有软404

**Core Web Vitals**
- LCP < 2.5s
- INP < 200ms
- CLS < 0.1
- 服务器响应时间优化
- 图片优化

**On-Page**
- Title tags 优化（60字符，关键词位置）
- Meta descriptions 吸引人（155字符）
- Header 层级（H1 → H2 → H3）
- 内部链接到优先页面

**E-E-A-T**
- 展示作者专业知识
- 清晰的来源和引用
- 定期内容更新
- 准确、全面的信息

3. **CTA Optimization**
   - 行动导向（不是"Submit"）
   - 与页面对比
   - 首屏放置

4. **Friction Analysis**
   - 移除不必要的表单字段
