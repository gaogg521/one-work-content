# NEAR Best Practices Guide Skill

Comprehensive best practices for NEAR wallet, contracts, and DeFi.

## 描述

This skill provides best practices guidance for NEAR development, covering wallet security, contract patterns, DeFi safety, and more. Includes 100+ terms and explanations accessible via CLI 命令.

## 功能特性

- Browse best practices by category
- 搜索 specific terms
- 获取 detailed explanations
- Quick 参考 guides
- Security guidelines

## 命令

### `near-best browse [category]`
Browse best practices by category.

**Categories:**
- wallet - Wallet security and management
- contracts - Smart contract best practices
- defi - DeFi safety guidelines
- keys - Private key management
- gas - Gas optimization
- testing - Testing and deployment

### `near-best search <term>`
搜索 a specific term or keyword.

### `near-best get <term>`
获取 detailed explanation for a specific term.

### `near-best list`
列表 all available terms.

### `near-best random`
获取 a random best practice 提示.
