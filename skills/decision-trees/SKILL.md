# 决策树 —— 结构化决策制定

决策树分析：一种用于处理概率和期望值的决策可视化工具。

## 何时使用

✅ **适用于：**
- 商业决策（投资、招聘、产品发布）
- 个人选择（职业、搬迁、购买）
- 交易与投资（仓位大小、进出场）
- 运营决策（扩张、外包）
- 任何具有可衡量后果的情况

❌ **不适用于：**
- 真正不确定的决策（黑天鹅事件）
- 快速战术选择
- 纯粹的情感/伦理问题

## 方法

**决策树** = 树状结构，其中：
- **决策节点**（方块）—— 你的行动
- **机会节点**（圆圈）—— 随机事件
- **终止节点**（三角形）—— 最终结果

**流程：**
1. **定义选项** —— 所有可能的行动
2. **定义结果** —— 每个行动后可能发生的情况
3. **估计概率** —— 每个结果的可能性（0-100%）
4. **估计价值** —— 每个结果的效用/回报（金钱、分数、效用单位）
5. **计算 EV** —— 期望值 = Σ (概率 × 价值)
6. **选择** —— 期望值最高的选项

## 公式

```
EV = Σ (probability_i × value_i)
```

**示例：**
- 结果 A：70% 概率，+$100 → 0.7 × 100 = $70
- 结果 B：30% 概率，-$50 → 0.3 × (-50) = -$15
- **EV = $70 + (-$15) = $55**

## 经典示例（来自 Wikipedia）

**决策：** 去参加派对还是待在家里？

### 估计：
- 派对：+9 效用（乐趣）
- 家里：+3 效用（舒适）
- 不必要地携带夹克：-2 效用
- 感到寒冷：-10 效用
- 寒冷概率：70%
- 温暖概率：30%

### 树：

```
Decision
├─ Go to party
│  ├─ Take jacket
│  │  ├─ Cold (70%) → 9 utility (party)
│  │  └─ Warm (30%) → 9 - 2 = 7 utility (carried unnecessarily)
│  │  EV = 0.7 × 9 + 0.3 × 7 = 8.4
│  └─ Don't take jacket
│     ├─ Cold (70%) → 9 - 10 = -1 utility (froze)
│     └─ Warm (30%) → 9 utility (perfect)
│     EV = 0.7 × (-1) + 0.3 × 9 = 2.0
└─ Stay home
   └─ EV = 3.0 (always)
```

**结论：** 去参加派对并带上夹克（EV = 8.4）> 待在家里（EV = 3.0）> 不带夹克去（EV = 2.0）

## 商业示例

**决策：** 发布新产品？

### 估计：
- 成功概率：40%
- 失败概率：60%
- 成功时利润：$500K
- 失败时亏损：$200K
- 不发布：$0

### 树：

```
Launch product
├─ Success (40%) → +$500K
└─ Failure (60%) → -$200K

EV = (0.4 × 500K) + (0.6 × -200K) = 200K - 120K = +$80K

Don't launch
└─ EV = $0
```

**结论：** 发布（EV = +$80K）优于不发布（$0）。

## 交易示例

**决策：** 开仓还是等待？

### 估计：
- 上涨概率：60%
- 下跌概率：40%
- 仓位大小：$1000
- 目标：+10%（$100 利润）
- 止损：-5%（$50 亏损）

### 树：

```
Enter position
├─ Rise (60%) → +$100
└─ Fall (40%) → -$50

EV = (0.6 × 100) + (0.4 × -50) = 60 - 20 = +$40

Wait
└─ No position → $0

EV = $0
```

**结论：** 开仓具有正期望值（+$40），优于等待（$0）。

## 方法局限性

⚠️ **关键点：**

1. **主观估计** —— 概率往往是“拍脑袋”
2. **不考虑风险偏好** —— 忽略心理因素（损失厌恶）
3. **简化模型** —— 现实更为复杂
4. **不稳定** —— 数据微小变化可能大幅改变树结构
5. **可能不准确** —— 存在更精确的其他方法（随机森林）

**但是：** 该方法对于**结构化思考**很有价值，即使数字只是近似值。

## 用户工作流

### 1. 结构化

询问：
- 有哪些行动选项？
- 可能的结果是什么？
- 每个结果的值/效用是多少？
- 我们如何衡量价值？（金钱、效用单位、幸福点数）

### 2. 概率估计

通过以下方式帮助估计：
- 历史数据（如果有）
- 可比情况
- 专家判断（用户经验）
- 主观评估（如果没有数据）

### 3. 可视化

用 markdown 绘制树：

```
Decision
├─ Option A
│  ├─ Outcome A1 (X%) → Value Y
│  └─ Outcome A2 (Z%) → Value W
└─ Option B
   └─ Outcome B1 (100%) → Value V
```

### 4. EV 计算

对于每个选项：
```
EV_A = (X% × Y) + (Z% × W)
EV_B = V
```

### 5. 建议

期望值最高的选项 = 理性上的最佳选择。

**但需补充背景：**
- 风险承受能力（用户能否承受最坏情况）
- 时间范围（何时需要结果）
- 其他因素（声誉风险、情感、伦理）

## 按领域分类的应用示例

### 交易与投资

**仓位大小：**
- 选项：资本的 5%、10%、20%
- 结果：不同概率下的盈亏
- 价值：绝对利润（$）

**入场时机：**
- 选项：立即入场、等待 -5%、等待 -10%
- 结果：价格上涨/下跌
- 价值：机会成本 vs 更好的入场价

### 商业策略

**产品发布：**
- 选项：发布 / 不发布
- 结果：成功 / 失败
- 价值：收入、市场份额、成本

**招聘决策：**
- 选项：录用候选人 A / 候选人 B / 不录用
- 结果：成功入职 / X 个月后离职
- 价值：生产力、成本、机会成本

### 个人决策

**职业转换：**
- 选项：留下 / 换工作 / 创业
- 结果：新角色中的成功 / 失败
- 价值：薪资、满意度、成长、风险

**房地产：**
- 选项：购买房屋 A / 房屋 B / 继续租房
- 结果：价格上涨 / 下跌 / 个人情况变化
- 价值：净资产、月支出、生活质量

### 运营

**产能规划：**
- 选项：扩大生产 / 外包 / 维持现状
- 结果：需求增加 / 减少
- 价值：利润、利用率、固定成本

**供应商选择：**
- 选项：供应商 A / 供应商 B / 内部处理
- 结果：质量、可靠性、故障
- 价值：总拥有成本

## 计算器脚本

使用 `scripts/decision_tree.py` 进行自动 EV 计算：

```bash
python3 scripts/decision_tree.py --interactive
```

或通过 JSON：

```bash
python3 scripts/decision_tree.py --json tree.json
```

JSON 格式：

```json
{
  "decision": "Launch product?",
  "options": [
    {
      "name": "Launch",
      "outcomes": [
        {"name": "Success", "probability": 0.4, "value": 500000},
        {"name": "Failure", "probability": 0.6, "value": -200000}
      ]
    },
    {
      "name": "Don't launch",
      "outcomes": [
        {"name": "Status quo", "probability": 1.0, "value": 0}
      ]
    }
  ]
}
```

输出：

```
📊 Decision Tree Analysis

Decision: Launch product?

Option 1: Launch
  └─ EV = $80,000.00
     ├─ Success (40.0%) → +$500,000.00
     └─ Failure (60.0%) → -$200,000.00

Option 2: Don't launch
  └─ EV = $0.00
     └─ Status quo (100.0%) → $0.00

✅ Recommendation: Launch (EV: $80,000.00)
```

## 最终检查清单

在给出建议之前，确保：

- ✅ 所有选项已涵盖
- ✅ 每个分支的概率总和为 100%
- ✅ 价值是现实的（不是幻想）
- ✅ 最坏情况对用户清晰
- ✅ 风险/回报比率明确
- ✅ 提及方法局限性
- ✅ 添加了定性背景（不仅仅是 EV）

## 方法优势

✅ **简单** —— 人们直观理解树
✅ **可视化** —— 结构清晰
✅ **数据需求少** —— 可以使用专家估计
✅ **白盒** —— 逻辑透明
✅ **最坏/最好情况** —— 极端场景可见
✅ **多决策者** —— 可以考虑不同利益

## 方法劣势

❌ **不稳定** —— 数据微小变化 → 树大幅变化
❌ **不准确** —— 通常存在更精确的方法
❌ **主观** —— 概率估计“拍脑袋”
❌ **复杂** —— 结果过多时变得难以处理
❌ **不考虑风险偏好** —— 假设风险中性

## 重要提示

该方法对于**结构化思考**很有价值，但数字往往是凭空捏造的。

更重要的是过程 —— **强迫自己思考所有分支**并明确评估后果。

不要将决策标榜为“科学证明” —— 它只是一个有意识选择的框架。
