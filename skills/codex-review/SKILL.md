# codex-review

## 概述

专业的代码审查，自动生成 CHANGELOG，与 Codex AI 集成

## 何时使用

- 当您需要在提交前进行专业代码审查时
- 当您需要自动生成 CHANGELOG 时
- 当审查大规模重构时

## 安装

```bash
npx skills add -g BenedictKing/codex-review
```

## 分步指南

1. 使用上述命令安装 skill
2. 确保已安装 Codex CLI
3. 使用 `/codex-review` 或自然语言触发器

## 示例

有关示例，请参见 [GitHub Repository](https://github.com/BenedictKing/codex-review)。

## 最佳实践

- 将 CHANGELOG.md 保存在项目根目录
- 使用 conventional commit 消息
