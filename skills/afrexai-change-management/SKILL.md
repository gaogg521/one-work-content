# Change Management Planner

使用结构化框架规划、沟通并执行组织变革。涵盖技术推广、流程变更、重组和文化转型。

## 它能做什么

当给定一个变革计划时，生成：
1. **利益相关者影响评估** —— 谁受影响、如何影响、阻力可能性（1-5）
2. **沟通计划** —— 按受众（高管、经理、一线员工）划分的消息时间线
3. **培训与赋能计划** —— 技能差距、培训形式、时间线
4. **阻力缓解** —— 预期反对意见 + 具体回应
5. **推广阶段** —— 试点 → 受控推广 → 全面部署，包含 go/no-go 关卡
6. **成功指标** —— 采用率、生产力影响、情绪评分、时间线遵守度

## 支持的框架

- **ADKAR**（Awareness, Desire, Knowledge, Ability, Reinforcement）
- **Kotter's 8-Step**（Urgency → Coalition → Vision → Communication → Empowerment → Quick Wins → Consolidation → Anchoring）
- **Lewin's**（Unfreeze → Change → Refreeze）

## 使用方法

告诉 agent 你的变革计划：
- 正在改变什么以及为什么
- 时间线和预算限制
- 组织规模和文化
- 之前的变革尝试（成功/失败）

agent 会选择最佳框架并生成完整的变革管理计划。

## 输出格式

结构化 markdown，包含：
- 执行摘要（1 段）
- 利益相关者地图（表格：group | impact | resistance | strategy）
- 分阶段时间线，包含负责人和里程碑
- 每个阶段的沟通模板
- 风险登记册及缓解措施
- 30/60/90 天成功指标

## 何时使用

- 推广新软件（ERP、CRM、AI 工具）
- 重组团队或部门
- 改变业务流程或工作流
- 并购整合
- 文化转型计划
