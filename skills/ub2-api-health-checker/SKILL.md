# API 健康检查器

一个让 Claw 能够测试 API 端点、验证响应、测量性能并生成健康报告的技能。

## 功能

提供系统的 API 测试和监控工作流：

1. **端点测试** — 向指定的 API 端点发送 HTTP 请求（GET、POST、PUT、DELETE）
2. **响应验证** — 检查状态码、响应时间和响应体结构是否符合预期值
3. **认证支持** — 处理 API 密钥、Bearer 令牌和基本认证请求头
4. **性能测量** — 记录响应时间并标记慢速端点
5. **健康报告** — 生成综合报告，汇总所有测试端点的状态

## 使用方法

提供 API 端点，Claw 将对其进行测试：

- "检查 https://api.example.com/v1/status 是否正常响应"
- "测试此 API 的所有端点并报告哪些正在失败"
- "监控这 5 个端点并告诉我它们的平均响应时间"
- "验证 /users 端点是否返回包含预期字段的 JSON 数组"

## 配置

你可以指定：
- **端点** — 要测试的 URL 列表
- **预期状态码** — 每个端点应返回的 HTTP 状态码（默认：200）
- **超时** — 每个请求的最大等待时间（默认：10 秒）
- **请求头** — 包含认证令牌的自定义请求头
- **请求体** — 用于 POST/PUT 请求

## 输出

健康报告包括：
- **状态摘要** — 测试的端点总数、通过、失败和超时数
- **每个端点的详细信息** — URL、方法、状态码、响应时间和通过/失败结果
- **性能指标** — 平均、最小、最大和 P95 响应时间
- **建议** — 针对慢速或返回错误的端点的建议
