# Fizzy CLI

此仓库包含一个独立的 CLI。

## 安装

```bash
npm i -g @emredoganer/fizzy-cli
```

## 认证

在 Fizzy 中生成个人访问令牌：

```bash
fizzy auth login
```

（你将被提示输入你的令牌。）
